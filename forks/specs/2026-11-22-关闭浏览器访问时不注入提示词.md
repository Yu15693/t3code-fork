# 关闭浏览器访问时不注入提示词

## 背景与决定

设置项 `enableAgentBrowserAccess` 关闭后，MCP 服务端会从会话凭据中移除 `preview` 能力并在 `tools/list` 中过滤掉 `preview_*` 工具，同时在 `McpProviderSessionConfig` 上提供 `browserToolsAvailable: false`。

但此前只有 Codex 路径按该开关省略 `T3_CODE_BROWSER_TOOL_INSTRUCTIONS`，且共享编排段 `Visuals and preview` 中仍无条件包含 `preview_*` 使用规则；ACP 驱动也未将 `browserToolsAvailable` 纳入 `T3AcpInstructionState`，导致关闭开关后仍会向模型注入 `## T3 Code browser` 及 `preview_*` 规则，干扰模型选择其他可用的浏览器自动化方式。

本补丁将所有 `preview_*` 规则收口到 `T3_CODE_BROWSER_TOOL_INSTRUCTIONS`，并在各 Provider 路径统一按 `browserToolsAvailable` 条件注入。

## 行为约定

- `enableAgentBrowserAccess` 关闭（`browserToolsAvailable === false`）时，Codex、ACP、Claude、Cursor、OpenCode 均不注入 `## T3 Code browser` 及任何 `preview_*` 规则。
- 图表与 HTML 渲染规则（`html_preview` / `html_render`）保留在共享编排段的 `### Visuals` 中，不受浏览器访问开关影响。
- `enableAgentBrowserAccess` 开启（`browserToolsAvailable === true`）时，各 Provider 仍收到完整的浏览器提示词，保持既有行为；ACP 会话中该状态变化时会重新下发指令。

## 修改方式

- [orchestrationInstructions.ts](../../packages/provider-core/src/server/orchestrationInstructions.ts)：将 `Visuals and preview` 中的 `preview_*` 条目移入 `T3_CODE_BROWSER_TOOL_INSTRUCTIONS`，共享段保留 `### Visuals`；为 `T3AcpInstructionState`、`t3AcpPromptWithInstructions`、`t3OrchestrationPrompt` 和 `t3OrchestrationSystemPrompt` 增加 `hasBrowserTools` 开关判断。
- [adapter.ts](../../packages/provider-acp/src/server/adapter.ts)：在 `instructionState` 中读取 `mcpSession?.browserToolsAvailable === true`。
- [ClaudeAdapterV2.ts](../../apps/server/src/orchestration-v2/Adapters/ClaudeAdapterV2.ts)、[adapter.ts](../../packages/provider-cursor/src/server/adapter.ts)、[adapter.ts](../../packages/provider-opencode/src/server/adapter.ts) 与 [v2/adapter.ts](../../packages/provider-opencode/src/server/v2/adapter.ts)：读取 `mcpSession?.browserToolsAvailable === true` 并按该状态决定是否拼接浏览器提示词。
- 同步更新 [agentContextBudget.json](../../apps/server/src/provider/agentContextBudget.json) 与对应单测。

## 验证方式

- 源码层面运行 [共享指令测试](../../packages/provider-core/src/server/orchestrationInstructions.test.ts)、[Codex 上下文测试](../../apps/server/src/provider/CodexDeveloperInstructions.test.ts) 和 [上下文预算测试](../../apps/server/src/provider/AgentContextBudget.test.ts)。
- 实际使用中在关闭与开启 `Agent browser access` 后分别新建会话，确认关闭时既无 `preview_*` 工具也无对应提示词注入，开启时行为正常。

## 移除条件

上游在关闭 `enableAgentBrowserAccess` 时，ACP 及各 Provider 均不再注入 `## T3 Code browser` 和 `preview_*` 规则后，不再迁移本补丁。
