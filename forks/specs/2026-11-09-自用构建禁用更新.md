# 自用构建禁用更新

状态：源码已实现，构建配置测试通过；尚未构建或验证成品。

## 目标与方案

自用 macOS 桌面包保留本地补丁，由维护者选择稳定版、重新构建并手动安装，避免应用内更新替换自建版本。

`v0.1.7` 的 [DesktopUpdates](../../apps/desktop/src/updates/DesktopUpdates.ts) 已在没有更新源时将更新状态设为 `disabled`，跳过更新器初始化和定时检查，并拒绝检查、下载和安装操作。复用这条路径即可。

在 [构建脚本](../../scripts/build-desktop-artifact.ts) 的 `createBuildConfig` 返回前固定设置 `publish: null`，覆盖 `T3CODE_DESKTOP_UPDATE_REPOSITORY`、`GITHUB_REPOSITORY` 或 mock 配置提供的更新源。保留上游配置拼装以减少 Fork 差异，最终交给 electron-builder 的配置始终不包含更新源，普通桌面启动也无需依赖终端环境变量。

现有 `T3CODE_DISABLE_AUTO_UPDATE` 是运行时环境变量，仅在打包终端设置不会固化到成品，本方案不依赖它。自用环境不另配组织策略的 `feedUrl` 或启用运行时 mock 更新源；这两项能够绕过“包内无更新源”的前提。

桌面托管服务的[更新请求](../../apps/server/src/cloud/selfUpdate.ts) 转交桌面应用，因此随桌面包一起维护。独立 `t3` 后台服务和 Provider CLI 的更新不属于本补丁范围。

## 验证

1. 最小修改现有构建测试：将正式版本原本期待的 GitHub 更新源改为 `null`，保留预览版本检查；打包后再确认安装包没有更新源元数据。
2. 按[维护指南](../README.md#构建验证与恢复)隔离试用成品，从 Finder 或 Dock 启动并重启，确认更新状态为禁用、没有检查或下载行为，且本地服务来自自建包。记录产物、提交和验证结果。

现有构建测试的 48 项检查及相关包类型检查通过。本次不扩展组合测试，也不修改桌面更新逻辑及其测试；成品启动验证待执行。

切回官方应用，或上游提供经过成品验证的等效配置时，可移除此补丁；升级和恢复继续遵循维护指南。
