# 浏览器工具选择

状态：源码已实现，单元测试和类型检查通过；真实模型评测及安装包验证待完成。

## 背景与决定

`v0.1.7` 的共享提示词要求浏览器任务使用 `preview tools only`，专用浏览器段又要求先使用 T3 工具、仅在特定条件下切换。用户指定 Playwriter 等方式时，这些文字可能阻止 Agent 遵循要求。

本补丁只调整提示词的工具选择规则，让 Agent browser access 可以保持开启：用户明确指定方式时按指定执行，未指定时默认使用可用的 T3 浏览器工具。各 Provider 保留原有注入路径，避免为这项偏好调整重构适配器。

## 行为约定

- 用户明确指定浏览器、自动化工具或要求使用某个 Skill 时，按该方式执行，无需先尝试 T3 工具。
- 用户未指定方式时，默认使用可用的 T3 `preview_*` 工具。仅安装了某个 Skill 不自动覆盖这个默认；用户明确要求使用的 Skill 指定了工具时，视为用户指定方式。
- 用户指定的方法不可用时，说明限制；这不构成静默改用 T3 的理由。默认 T3 路线不可用、不支持或同一步骤连续失败两次时，可说明原因后采用其他可用方式。
- 公共网页研究未要求浏览器操作时，仍可使用 web fetch 或搜索。使用 T3 浏览器时保留原有的状态检查、定位方式和页面清理要求。
- 浏览器开关继续控制现有权限。本补丁不改变工具注册、权限检查或会话刷新，也不保证关闭后所有浏览器说明文字消失。

## 修改位置与替换文案

产品代码只修改 [orchestrationInstructions.ts](../../packages/provider-core/src/server/orchestrationInstructions.ts) 中以下两处字符串。通用段中的图表展示规则、委派规则、设备规则和其他内容保持原状。

### 通用段

替换 `T3_CODE_ORCHESTRATION_SECTIONS` 中 `Visuals and preview` 下以 `Never use preview_*` 开头的条目：

```text
- For browser work, follow the user's explicit choice of browser or automation method, including a skill they explicitly request. Otherwise, default to T3's preview_* tools when available. An explicit choice takes precedence over this default; do not require trying T3 tools first. If the requested method is unavailable, explain the limitation instead of silently substituting another tool. Use web fetch or search for public pages unless browser work was requested. Never use preview_* unasked to verify or show your own edit. Do not repeat preview calls from an earlier turn. Close a tab you opened before you reply, unless the user asked for it or uses it.
```

落入 TypeScript 字符串时，工具名沿用现有反引号格式。删除原条目中的 `preview tools only, no web fetch`，不保留与新选择规则冲突的旧句子。

### 浏览器专用段

保留 `T3_CODE_BROWSER_TOOL_INSTRUCTIONS` 的标题，替换其正文：

```text
Respect the user's explicit choice of browser or automation method, including a skill they explicitly request. No T3 attempt is required first. If no method is specified, default to T3's preview_* tools when available. When using them, call preview_status first, then preview_open if no tab can be automated, and prefer snapshot locators over coordinates. If the default T3 route is unavailable, preview_open reports unsupported, or two preview calls fail on one step, explain the issue and use another available method. A user-requested switch does not require a tool error.
```

两段保持相同的选择优先级。专用段提供选择 T3 之后的操作说明，不再要求用户先满足失败条件才能采用指定工具。

## 消费路径与影响

Codex 使用共享段，并按浏览器可用性追加专用段；ACP 当前按 MCP 是否启用追加专用段。Claude、Cursor、OpenCode 和 Pi 的相关注入路径使用共享段。因此两段都要调整，收到两段或只收到共享段的 Agent 都能得到一致的工具选择规则。

无需增加生成函数、传递新参数或移动提示词。工具能否实际调用仍由原权限和运行环境决定；源码中的消费关系不能代替各 Provider 的运行验证。

## 验证

按本次确认的最小补丁范围，不新增提示词字符串测试、不扩展工具开关测试，也不修改 `evals/`。运行原有 [共享指令测试](../../packages/provider-core/src/server/orchestrationInstructions.test.ts) 和 [Codex 上下文测试](../../apps/server/src/provider/CodexDeveloperInstructions.test.ts)，检查既有行为及每项 additionalContext 的 4,000 字节限制。

真实模型评测此前因缺少代理配置未能启动。实际工具选择留待自建包的新会话验证：开启 Agent browser access，分别检查用户指定 Playwriter、明确指定 Skill、未指定方式及指定方法不可用四种情况。媒体导航前先静音，记录实际验证的 Provider。测试通过不代表模型行为已经验证。

原有共享指令与 Codex 上下文测试通过，相关包类型检查已通过。安装包信息按 [维护指南](../README.md) 记录；当前安装版本尚未替换，本会话不会自动采用仓库中的新规则。
