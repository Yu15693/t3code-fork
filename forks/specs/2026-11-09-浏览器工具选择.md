# 浏览器工具选择

## 背景与决定

上游共享提示词要求浏览器任务使用 `preview tools only`，专用浏览器段要求先使用 T3 工具，只在工具缺失、不支持、连续失败或用户要求时切换。用户指定 Playwriter 等方式时，这些文字可能让 Agent 先尝试 T3 工具，或在切换时编造失败理由。

本补丁只调整提示词中的工具选择规则，让 Agent browser access 可以保持开启：用户明确指定方式时按指定执行，未指定时默认使用可用的 T3 浏览器工具。各 Provider 保留原有注入路径，不为这项偏好重构适配器。

## 行为约定

- 用户明确指定浏览器、自动化工具或要求使用某个 Skill 时，按该方式执行，无需先尝试 T3 工具。
- 用户未指定方式时，默认使用可用的 T3 `preview_*` 工具。仅安装了某个 Skill 不自动覆盖这个默认；用户明确要求使用的 Skill 指定了工具时，视为用户指定方式。
- 用户指定的方法不可用时，说明限制，不静默改用其他工具。默认 T3 路线缺失、不支持或同一步骤连续失败两次时，引用错误后切换。
- 未要求浏览器操作的公共网页研究仍可使用 web fetch 或搜索；已要求浏览器操作时只用浏览器工具。使用 T3 浏览器时保留原有的状态检查、定位方式和页面清理要求。
- 浏览器开关继续控制现有权限。本补丁不改变工具注册、权限检查或会话刷新。

## 修改方式

只修改 [orchestrationInstructions.ts](../../packages/provider-core/src/server/orchestrationInstructions.ts) 中的两处浏览器文字，其余内容保持上游原样：

- **共享段**：把 `Visuals and preview` 下原有的 preview 条目拆成两条。第一条先定义什么算浏览器任务，再给出选择顺序：用户明确选择的方式优先，不可用时说明；未选择时使用 T3 `preview_*`；浏览器任务不用 web fetch。第二条保留上游关于不擅自验证、不重复调用和关闭标签页的要求。
- **浏览器专用段**：只说明使用 T3 浏览器时怎么操作，以及默认路线失败后如何切换，不重复选择规则。

Codex 使用共享段，并按浏览器可用性追加专用段；ACP 按 MCP 是否启用追加专用段；Claude、Cursor、OpenCode 和 Pi 只使用共享段。收到专用段的路径都同时收到共享段，因此选择规则只写在共享段，专用段不重复。提示词变化会改变 [agentContextBudget.json](../../apps/server/src/provider/agentContextBudget.json) 中的字节快照，随本补丁一起更新。

## 验证方式

源码层面运行 [共享指令测试](../../packages/provider-core/src/server/orchestrationInstructions.test.ts)、[Codex 上下文测试](../../apps/server/src/provider/CodexDeveloperInstructions.test.ts) 和 [上下文预算测试](../../apps/server/src/provider/AgentContextBudget.test.ts)，检查既有行为、每项 additionalContext 的 4,000 字节限制和预算快照。

模型实际行为在安装包的新会话中检查：开启 Agent browser access，分别验证用户指定 Playwriter、明确指定 Skill、未指定方式及指定方法不可用四种情况，并记录验证的 Provider。测试通过不代表模型行为已经验证。

## 移除条件

所选官方稳定版已经允许用户指定方式优先、未指定时默认 T3，且其他注入段没有冲突要求，经实际工具选择验证后，不再迁移本补丁。
